## 📌 1. Visão Geral do Repositório

Este repositório é o **portfólio acadêmico consolidado do meu 1º Semestre no curso técnico do SENAI**. Nele reuni todos os conceitos teóricos, pesquisas de campo, documentações de requisitos, atividades práticas de lógica e projetos integradores desenvolvidos ao longo das disciplinas iniciais da formação em Tecnologia da Informação e Desenvolvimento de Software.

O conteúdo está organizado em **4 pilares fundamentais (disciplinas)**:
1. **`LOPAL`** - Lógica de Programação e Algoritmos
2. **`LER`** - Levantamento e Especificação de Requisitos
3. **`ARI`** - Arquitetura de Redes, Infraestrutura e Aplicações Web
4. **`SOP`** - Sistemas Operacionais, Servidores e Segurança

## 🚀 2. O Que Foi Desenvolvido em Cada Disciplina

### 🧠 LOPAL — Lógica de Programação e Algoritmos (`/LOPAL`)
Foco na construção do raciocínio lógico, estruturas algebrópicas, algoritmos visuais e programação em Python.
- **Algoritmos em Fluxograma (`S1_R2---AT1_LOPAL`):** Modelagem de algoritmos visuais em Flowgorithm (`.fprg`) para cálculo de médias, checagem de maioridade (`idade`), paridade e números positivos/negativos.
- **Fundamentos do Python (`aprendendo_o_python`):**
  - **Sintaxe & Operadores:** Entrada/saída de dados (`input`, `print`), operadores aritméticos e relacionais.
  - **Estrutura de Decisão & Laços:** `if/elif/else`, laços de repetição (`for` e `while`).
  - **Manipulação de Textos & Estruturas:** Fatiamento de strings, listas, tuplas, dicionários e matrizes bidimensionais.
  - **Modularização & Funções:** Definição de rotinas com `def`, passagem de parâmetros, escopo de variáveis e retorno de valores (`return`).
- **Resolução de Problemas (`S1_R3---AT1_LOPAL_T1`):** Lista com 11 exercícios práticos em Python resolvendo desafios numéricos e lógicos.

---

### 📋 LER — Levantamento e Especificação de Requisitos (`/LER`)
Foco em Engenharia de Software, documentação de sistemas e metodologias de desenvolvimento.
- **Documentação de Requisitos (`DocumentacaoRequisitos/ProjetoSGT`):** Elaboração de Termo de Abertura de Projeto (TAP), especificação de Requisitos Funcionais (RF) e Não-Funcionais (RNF) e Diagramas de Casos de Uso.
- **Controle de Versão (`AtividadeDEcontroledeversao`):** Práticas fundamentais de Git e GitHub (branches, commits, merge e pull requests).
- **🏆 Projeto Final — QuickParking (`projeto_final_ler`):**
  - Desenvolvido em dupla por *João Wictor* e *Beatriz Bergamin*.
  - Sistema completo em Python para gestão de estacionamento comercial de posto de combustível.
  - Funcionalidades: Controle de vagas em tempo real, registro de entrada/saída de veículos, cálculo automático de tempo de permanência/tarifas e geração de relatórios gerenciais.

---

### 🌐 ARI — Arquitetura de Redes & Aplicações Interativas (`/ARI`)
Foco em infraestrutura web, modelos cliente-servidor e desenvolvimento de aplicações backend/frontend.
- **🏆 Projeto Sistema-Login (`Sistema-Login`):**
  - Aplicação Web responsiva desenvolvida com **Python + Flask**.
  - **Backend (`app.py`):** Configuração de rotas HTTP, motor Flask e lógica de autenticação de usuários.
  - **Frontend (`templates/index.html` & `static/style.css`):** Interface limpa de login com estilização CSS3 customizada e imagem de fundo.
  - **Documentação:** Relatório técnico e capturas de tela das etapas de testes e validações na porta `8000`.

---

### 💻 SOP — Sistemas Operacionais & Segurança (`/SOP`)
Foco em administração de sistemas Linux, servidores, firewall e políticas de segurança da informação.
- **🏆 Projeto Final de Servidores e Segurança (`projeto_final_sop`):**
  - **Instalação e Configuração (`instalacao.md`):** Deploy e administração de servidor Linux Debian 12 / Ubuntu Server via CLI.
  - **Gestão de Perímetro & Firewall:** Configuração do **UFW** (*Uncomplicated Firewall*) definindo regras de acesso (`ufw allow`, `deny`, `limit`).
  - **Conectividade Segura:** Implantação e validação de serviço **OpenVPN** com autoridade certificadora **Easy-RSA**.
  - **Segurança da Informação (`psi.md` & `relatorio_e_analise_de_vulnerabilidade.md`):** Mapeamento de vulnerabilidades, hardenning de servidor e elaboração de Política de Segurança da Informação (PSI).

## 💻 4. Como Executar e Testar os Projetos

### 1. Testar Exercícios de Python (LOPAL / QuickParking):
```bash
# Executar exercício de Lógica
python LOPAL/S1_R3---AT1_LOPAL_T1/"01 - Exercicio.py"

# Executar o Projeto QuickParking
python LER/projeto_final_ler/projeto_ler.py
```

### 2. Executar a Aplicação Web Flask (ARI - Sistema Login):
```bash
cd ARI/Sistema-Login
pip install flask
python app.py
```
Acesse no navegador: `http://localhost:8000`

### 3. Visualizar Diagramas e Documentações Linux (SOP / LER):
Abra os arquivos `.md` diretamente no GitHub ou VS Code:
- Documentação do Servidor Linux: [`SOP/projeto_final_sop/instalacao.md`](./SOP/projeto_final_sop/instalacao.md)
